# #673 追查与 #674 集成说明

## 连接采样

原扩展失败等待切备用线路后的 bootstrap 200。已确定本功能的共享 `connectionFetch` 会把统计响应记为业务健康证据，并可能准备备用身份；一个使用真实 ConnectionController 的核心检查稳定捕获了该副作用（修复前 unknown → reachable，修复后状态不变）。统计现在仅通过已有身份验证的线路地址低优先级发送，不准备身份、不参与健康和切线、不重试。原连接采样两引擎通过。它消除了本次改动引入的确定干扰，但不能据此证明原 CI 那一次超时的唯一根因。

## 离线恢复

首次 CI 截图确为恢复页，不是仅等主模块变量的时序问题。未包含本功能的 main `e566a69` 与修复分支均完成本地双版本升级、离线重开、原 MXL 保留、渲染及非零音频播放检查，未复现原异常。离线导航在应用主模块执行前失败，报告器离线时不运行；目前没有证据证明由新统计造成，也无法排除之前在线阶段的时序关联。

未修改 service-worker 发布或恢复运行时，不增加重试或放宽断言。只在现有失败分支增加合成环境下的显示许可、shell 完成状态和文档信息，供再现时定位。最终 CI 结果与剩余限制记录在 PR 描述。

## 组合顺序与口径

分支基于已合并 #674 的 main `ce82b13b95bc3c5a5776a51dacd774326c88c625`。0039 统一管理员迁移、迁入来源、只读兼容视图及共享浏览器 fixture 均保持 main 原样；本 PR 的 0040 在其后执行，迁移保留性验证为独立步骤。Worker 测试只向统一表授权。截图与浏览器链路采用同一统一管理员合成身份，五个后台入口均可见并逐一验证，截图不表示生产数据或真实 iPadOS 验收。最终 head 的验证结果记录在 PR 描述。

运营身份按访问发生时排除。成员访问后才成为管理员时，原合法记录仍计入当前有效成员的窗口人数，新的管理员访问不刷新记录；该边界已加入核心 D1 检查。

## 回退

支持的 Worker 回退产物必须保留每小时的访问元数据清理，不能直接回退到完全没有该任务的旧二进制却继续保留成员数据。ADR-0022 提供仅依赖已有 DB binding 的三行维护入口；回退前验证过期成员记录被删，云盘和无个人身份的聚合时间保留。没有新增清盘操作或生产维护任务，也没有执行生产迁移、合并或部署。
