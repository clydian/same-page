# 练习看谱布局与真实合唱谱校准 · #431

## 范围

手机、iPad 和桌面共用顶部谱面切换与结束、底部播放控制；MusicXML
重排大小由播放器自身调整。PDF 复用原阅读器的页面、手势和笔记显示，练习中仅保留浏览与页码总览。
本次没有数据库、服务端 API、笔记或持久偏好格式迁移。

采用 **80%** 作为共同默认：相较 100% 减少每组谱表占用的高度，iPad 能按内容
在一行容纳更多小节；70% 的歌词更小，没有作为默认。手机上的密集伴奏段落
仍可能一小节一行，不强制塞入两个小节。提供 60%–120% 的大小调整，点击比例

另用带歌词的真实谱确认：暂停时跳到较后小节，按目标小节系统的 bounds 定位。
此前立即调用 `scrollToCursor()` 可能取到旧光标，因此底部小节更新而谱面仍在前面。
缩放后重建首调数字，手动浏览保留可见系统及暂停跟随状态。

## 回归覆盖

`browser-tests/practice-reader-layout.test.mjs` 使用可公开提交的生成谱例，包含
弱起 `0` 与自定义 `25` 小节标号；Chromium/WebKit 检查 320×740、390×844、
844×390、820×1180、1180×820。

- 控制按钮及速度选择器触摸高度至少 44px，当前小节可见，谱面避让上下栏。
- 坐标拖动预览目标，释放才定位，前后小节仍按播放次序移动。
- 原始 XML 小节标号与重复展开后的播放次序分别保留，自定义标号也用于重排谱面。
- 首调数字首次默认全部声部；大小调整重排并保留手动浏览位置、播放位置和跟随状态。
- 触摸点击 PDF/XML 切换；PDF 不唤起普通工具，页码总览仍可用；结束后恢复普通阅读。
- 原有 MusicXML 合成声音、循环、混音、准备复用与公开体验本机笔记边界回归继续保留。

`playback-timeline.test.tsx` 检查取消、键盘、辅助输入和释放到轨道外的行为。
WebKit 原生 range 在 pointer 仍按住时会产生 element blur；事件记录为
`pointerdown → input → blur → input`。元素失焦只提交键盘操作，pointer 继续预览到
释放；window blur 或 pointercancel 取消。回归同时保留这一真实浏览器路径及其最小组件用例。

## Review 与边界

以 `6ff09db08abc5291f375f7767bf5a87b55d9d1c9` 为固定起点，独立 Standards 与
Spec review 均已完成。Spec review 提出原小节号遗漏，已补齐并追加复核；未保留阻塞项。

所有手机/iPad 结果均为浏览器模拟视口，未连接实体设备。Safari/PWA 实际手势、
系统安全区、手指遮挡及排练距离可读性仍需真机确认；测试通过不表示已部署或合并。
