# PDF 与重排谱面对照

## 行为约定

- XML 会话顶部为「原始 PDF／重排谱面／对照」，默认仍为重排谱面。
- 两块谱面默认各 50%。竖屏上下，宽屏或较矮的手机横屏左右。
- 分隔条支持拖动、方向键微调、Home/End 到边界、Enter 或双击恢复均分。
  为两块保留最小阅读空间；上下与左右比例在本机按身份分别保存。
- 原始 PDF 连续滚动、支持手势缩放和页码总览，保留当前可见笔记。
  对照的 PDF 位置和缩放与普通阅读器分别保留，不覆盖原阅读布局偏好。
- 重排谱面保留缩放、首调数字、播放高亮和自动跟随；手动浏览后可恢复跟随。
  PDF 浏览不暂停 XML 自动跟随；不提供两块位置映射或联动滚动。
- 三种视图及分隔比例变化保留同一播放器，播放、进度、速度和练习设置连续。
- 共用测量框提供两块区域的边界，PDF 与 XML 各自按真实容器尺寸排版。
  正常阅读器与对照 PDF 使用不同的临时视口保存键。
- 无 API、数据库、IndexedDB、笔记数据变更。新比例键为可丢弃的本机显示偏好；
  无法读写 localStorage 时仍可在当前会话调整。

## 本地验收

`browser-tests/practice-compare.test.mjs` 覆盖 Chromium/WebKit，包含：
390×844、820×1180、1440×1000、1180×820、844×390、320×740 的布局与均分，
分隔条拖动／键盘、方向独立比例、独立浏览、切换视图的位置保留、持续播放及结束恢复。

可通过 `COMPARE_PDF` / `COMPARE_XML` 指定本机真实谱例，
`COMPARE_SCREENSHOTS` 指定 Chromium 截图目录。真实谱与截图只保存在本机，勿提交公开仓库。
自动化 WebKit 与模拟触摸不替代 iPad/Safari/PWA 真机排练验收。

2026-10-17 本地验证：Node 24 类型检查、改动范围 ESLint、生产构建及 precache 校验通过；
播放与连续阅读定向组件测试 42 项通过。Chromium/WebKit 原有练习阅读回归 2 项通过，
新增对照流程在 Chromium 真实谱例与 WebKit 生成谱例下通过；Chromium 另通过原生触摸拖动。
真实谱例使用本机已有《Let my love be heard》，截图包含上述六种尺寸，均保存在
`artifacts/practice-compare/`。未进行生产部署或 Safari/PWA 真机验收。

快速布局调整曾触发 WebKit 的 ResizeObserver delivery-loop 错误；上下栏和分隔尺寸
改为在下一动画帧提交后，对应错误消失。播放连续性检查先确认进度实际推进，再验证
切换与调整仍保持播放，避免在音频引擎尚未启动时立即停止的测试竞态。

## 追加：三种视图共用轻量控件

原始 PDF、重排谱面、对照统一使用当前视图菜单及直接结束入口；取消对照谱面标题行，
PDF 页码与 XML 比例入口浮在谱面上。XML 单独与对照显示共用双指缩放和比例弹层，
恢复跟随按需浮现，不改变内容区域高度。缩放达到上下限后保留按钮焦点，使 Escape
仍可退出浮层；不可用方向仅通过 aria-disabled 表达并阻止操作。

播放键保持几何居中，前后定位对称；左侧为紧凑当前位置及原生速度选择，右侧为练习设置。
小节仅显示源编号，定位弹层分别展示源小节和播放次序／总数，选择草稿后明确跳转。
音频使用相同底栏并保留时间与前后十秒语义。练习内单独 PDF 使用与重排谱面协调的浅色底。

`practice-unified-controls.test.mjs` 检查手机 390×844、窄屏 320×740、桌面 1440×1000
下三种视图的居中、触摸尺寸、单行顶部、无标题占位、缩放恢复、定位草稿及速度连续性。
真实谱六张截图位于本机 `artifacts/practice-unified/{mobile,desktop}-{pdf,xml,compare}.png`，
实际界面截图保持当前缩放，不拼接或修改谱面。候选谱审查复用的缩放入口和已有浏览器测试
一起更新；普通阅读器的显示／隐藏测试等待结束播放后的视口几何恢复，避免尺寸变化取消刚发出的点击。

追加验证结果：Node 24 类型检查、全仓 ESLint、生产构建和 precache 校验通过；播放组件
29 项测试通过。统一控件、播放声部／跟随／准备复用、缩放／定位／PDF 还原、候选谱审查、
以及公开体验 PDF/XML/音频和缺失入口状态均完成 Chromium/WebKit 回归。
真实谱例完成手机和桌面三种视图共六张截图，另检查了 320px 窄屏。
