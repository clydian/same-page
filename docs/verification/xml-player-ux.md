# XML 播放器声部练习界面

基于 `5d854a0`。范围是练习界面和共享播放器的可选首调数字显示，无 schema、API、已有个人混音存储格式变化。

- 播放条不重复 XML 名称，用可见的调节图标与「练习」打开混音面板，以「结束」结束播放会话。
- 声部关注始终在面板顶部可见，说明选定声部与其他声部的分组音量关系；退出恢复独立音量。
- 每声部名称、音量、静音与独奏同行。保留中文动作名和 44px 点击高度；联动/静音/独奏分别呈现。
- 练习面板的「谱面辅助」提供首调数字标准开关，明确显示开／关。复用 Chorus 的调号算法和音符坐标，重排后重新定位；不修改 XML 或播放位置。
- 小调采用 Chorus 的 la-based 6 约定。和弦密集、歌词密集的真实谱面仍需人工检查数字碰撞。

验证环境为 Node 24.21.0。构建、ESLint、播放偏好/生命周期/进度条客户端测试 13/13 通过。
Chromium / WebKit 的 `musicxml-playback.test.mjs` 和 `playback-ux.test.mjs` 合计 4/4 通过，覆盖播放声波输出、循环、PDF 交接、混音恢复、缓存复用与手机布局。
首调测试检查 48 小节 / 96 个音符，C 大调转 G 大调的 1/3 -> 4/6 标注；开关移除/重建标签、390px 重排后标签没有横向越界。
已查看桌面和手机混音与标数字谱面截图。浏览器自动化不等于真机排练或实际听觉验收。

后续 UI/UX 优先项：循环表单草稿应区别于正在生效的范围，避免修改表单后误以为循环已更新。

## 节拍与精细速度 · #575

- 新会话节拍器和跳转预备拍默认关闭，拍声使用固定默认音量，仅保留开关的会话内状态。切换 PDF／重排／对照沿用设置。
- 底栏倍率打开速度浮层，0.50–2.00×、步进 0.01×，提供加减与恢复 1.00×。滑动即时生效，同时显示当前位置原速及乘倍率后的实际速度；支持附点拍单位，小节内变速与反复经过按引擎展开的时间轴显示。
- 谱面辅助提供节拍器和「跳转后预备一小节」独立开关，拍声使用固定默认音量，不提供音量滑条。节拍器按分母单位打拍，首拍高音重拍；6/8、9/8、12/8 的其余三拍分组起点为次重拍。
- 进度、前后小节、定位和点击统一进入目标小节开头，保留循环边界和最近反复经过。播放中手动寻址先打一完整小节预备再入音乐；暂停中寻址保持暂停，下一次播放预备。普通暂停继续、首次播放、自动循环回起点不预备。
- 预备依据目标小节起始速度与拍号，弱起也预备完整拍号小节；界面按引擎实际预备位置显示拍次，谱面游标保持目标。暂停取消，连续寻址以最新目标为准。预备期间改倍率从新倍率重新预备。
- 循环范围草稿只预览，应用／取消恢复原播放状态，不额外预备。节拍器与音乐由同一 synth 排程；退出或失败会停止声音。
