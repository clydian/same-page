## 回退

当前应用没有自动切换逻辑，移除备用入口不会改变正式客户端的现有请求路径。
需要停止试验时：

1. 先确认没有新增调用者；在 Cloudflare 移除试验入口 CNAME，使新解析停止走 ESA。
2. 等待 DNS TTL／既有连接消退后，停用 ESA 入口和其规则。
3. 仅在不再需要自动续期时移除备用域名的 ACME CNAME 和对应证书。
4. 站点完全停止使用后再移除 `_esaauth`；删除站点不等于退订套餐，需单独检查订阅。
5. 保持正式域名、Worker、业务数据库、文件和本机离线数据不变。

实施回退前应复核控制台当前状态；本节不是已执行回退的记录。
