# 连接状态对照

2026-11-14 只读核对线上：stable `aa604ba`（v26.10.29.0903），beta/backend `04e6b27`（v26.11.13.2213），revision 44。两个线上入口脚本均包含“连接异常”“需处理”“可连接”“结果已过期”，均没有“浏览器离线”；两份源码的 ConnectionControl 相同。以下是条件启用时的状态清单，不能仅凭产物包含文案推断每个用户当前的运行状态。

## 左下入口

| 展示 | 线上 | #652 | 准确触发条件 |
| --- | --- | --- | --- |
| 浏览器离线 | 无此标签 | 新增 | `navigator.onLine=false`。只代表浏览器报告，部分操作据此暂停；不伪造线路失败样本。 |
| 连接异常 | 已有 | 保留 | 当前线路最新的连通性证据为失败，且未过 45 秒展示期限；PR 仅在浏览器没有报告离线时使用这个标签。证据来自业务观测或健康采样，取较新者，同毫秒分歧取失败。 |
| 需处理 | 已有 | 保留 | 当前线路 identity 为 conflict，且没有更优先的入口标签。实际比较的是入口 sessionId 与预期，可能是同一个用户的不同会话，不必然是不同的人。 |
| 转动图标／辅助名称“正在检测…” | 已有 | 保留 | `checking || preparing`，即主动检查或入口凭证准备中；可与前述文字并存。周期健康采样本身不设置这两个字段。 |
| Wifi 图标、没有文字 | 已有 | 保留 | 没有上述文字标签且未处于检查／准备。包括有可达证据、尚无证据、证据过期、身份 unknown/unprepared 等情况，不能统称为“全部正常”。 |

文字优先级：线上是 **连接异常 → 需处理 → 无文字**；PR 是 **浏览器离线 → 连接异常 → 需处理 → 无文字**。检查中的转动图标优先于 Wifi/WifiOff，但保留相应文字。非检查时，PR 的浏览器离线和连通性异常使用 WifiOff，其余使用 Wifi。

这几项是不同维度的条件，不是互斥的全局在线状态。同一时刻可以既有浏览器离线，又有旧成功采样或登录冲突，入口只优先显示一条。

## 面板当前线路

| 展示 | 条件 |
| --- | --- |
| 正在尝试直连／备用… | 有在途的另一线路尝试；不表示已经切换成功。 |
| 当前线路：直连／备用（暂时连不上） | 当前线路最新连通性展示为 unavailable。 |
| 当前线路：直连／备用（待检测） | 连通性证据 unknown 或 stale。 |
| 当前线路：直连／备用（待确认） | 有新鲜可达证据，但入口 identity 不为 ready。ready 只核对入口会话，并不保证应用已登录。 |
| 当前线路：直连／备用，无括号 | 有新鲜可达证据，入口 identity 为 ready。 |
| 末尾“· 浏览器离线” | PR 在浏览器报告离线时添加；不覆盖当前线路或尝试信息。 |

## 两条线路各自的检测结果

| 线上／PR 展示 | 条件 |
| --- | --- |
| 登录不一致 | 对应线路 identity 为 conflict，优先于采样成功／失败及采样过期。 |
| 结果已过期 | 最近采样超过 45 秒，且没有登录冲突。 |
| 可连接／线路可达 | 最近采样的 health 响应通过检查；PR 将文案从“可连接”改为“线路可达”。不证明身份、本机内容或更新正常。 |
| 暂时连不上 | 最近采样失败、超时、非成功响应或 JSON 不符合 health 要求。 |
| 尚未检测 | 尚无采样。 |

线路行只读最近健康采样；顶部与浮动入口还合并较新的业务观测，不能把它们当成同一次检查。

采样详情另有“正在检测…”（尚无样本）、“刚刚检测”、N 秒前检测、“检测已暂停”（页面隐藏）、“检测已过期”。这些是采样新鲜度，不是新增的账号或本机状态。正常可见面板每秒更新展示时钟；面板关闭时不持续采样或推进该时钟。

## 默认展示精简

PR 删除默认的两段范围解释，把浏览器离线压缩为当前线路旁的一条短提示；原有线路选择、结果和时间保留。状态解释合并进一个原生 details：“状态与连接帮助”，默认关闭，点击或键盘 Enter 展开。具体登录冲突／无法确认登录及“恢复连接”仍按原条件出现，不把必要异常处理藏进帮助。

帮助的展开不触发请求、切换线路、授予权限或改写检测历史。本次只调整展示，不取消浏览器门禁，也不声称解决身份接纳或本机工作空间等待。
