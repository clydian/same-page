# 连接状态对照

2026-11-14 只读核对线上：stable `aa604ba`（v26.10.29.0903），beta/backend `04e6b27`（v26.11.13.2213），revision 44。两个线上入口脚本均包含“连接异常”“需处理”“可连接”“结果已过期”，均没有“浏览器离线”；两份源码的 ConnectionControl 相同。以下是条件启用时的状态清单，不能仅凭产物包含文案推断每个用户当前的运行状态。

## 左下入口

PR 入口现在始终为固定尺寸的图标按钮，不显示“浏览器离线”“连接异常”或“需处理”等文字。外观表达概况，展开面板看原因；读屏仍能读到具体状态。

| 条件 | PR 外观 | 读屏状态名称 |
| --- | --- | --- |
| 浏览器报告离线 | 警示色 WifiOff | 浏览器离线 |
| 当前线路最新连通性证据失败，浏览器未报告离线 | 同样的警示色 WifiOff | 连接异常 |
| 当前线路会话 conflict，无前两项 | 警示色 Wifi | 需处理 |
| 入口身份 unprepared，无前述连通性异常 | 警示色 Wifi | 原有连接线路名称，面板显示待确认与恢复操作 |
| 正在检查或准备凭证 | 转动图标，可保持警示色 | 正在检测，可与上述辅助状态并存 |
| 没有上述情况 | 普通 Wifi | 连接线路 |

辅助名称的原因优先级是浏览器离线、连接异常、需处理；它不再决定按钮宽度或可见文字。非检查时浏览器离线与连通性异常使用相同 WifiOff；身份问题保留可达图标的警示色。转动图标优先于 Wifi/WifiOff。

无警示的 Wifi 也可能对应尚无证据、证据过期或身份 unknown，不能统称为所有功能正常。当前线路连通性展示仍合并业务观测与健康采样，取较新者，同毫秒分歧取失败；45 秒期限的展示时钟只在面板可见时推进。身份比较的是入口 sessionId 与预期，同一个用户的不同会话也可能 conflict。

## 面板当前线路

| 展示 | 条件 |
| --- | --- |
| 正在尝试直连／备用… | 有在途的另一线路尝试；不表示已经切换成功。 |
| 当前线路：直连／备用（暂时连不上） | 当前线路最新连通性展示为 unavailable。 |
| 当前线路：直连／备用（待检测） | 连通性证据 unknown 或 stale。 |
| 当前线路：直连／备用（待确认） | 有新鲜可达证据，但入口 identity 不为 ready。ready 只核对入口会话，并不保证应用已登录。 |
| 当前线路：直连／备用，无括号 | 有新鲜可达证据，入口 identity 为 ready。 |
| 当前线路：直连／备用（浏览器离线） | PR 在浏览器报告离线时优先显示这个括号原因；与“（暂时连不上）”格式一致，不重复追加其他括号。尝试另一线路时仍保留尝试信息及这个括号。 |

## 两条线路各自的检测结果

| 线上／PR 展示 | 条件 |
| --- | --- |
| 登录不一致 | 对应线路 identity 为 conflict，优先于采样成功／失败及采样过期。 |
| 结果已过期 | 最近采样超过 45 秒，且没有登录冲突。 |
| 可连接／线路可达 | 最近采样的 health 响应通过检查；PR 将文案从“可连接”改为“线路可达”。不证明身份、本机内容或更新正常。 |
| 暂时连不上 | 最近采样失败、超时、非成功响应或 JSON 不符合 health 要求。 |
| 尚未检测 | 尚无采样。 |

线路行只读最近健康采样；顶部与浮动入口还合并较新的业务观测，不能把它们当成同一次检查。

采样详情另有“正在检测…”（尚无样本）、“刚刚检测”、N 秒前检测、“检测已暂停”（页面隐藏）、“检测已过期”。这些是采样新鲜度，不是新增的账号或本机状态。正常可见面板每秒更新展示时钟；面板关闭时不持续采样或推进该时钟。

## 默认展示精简

PR 删除默认的两段范围解释，把浏览器离线压缩为当前线路后的括号提示；原有线路选择、结果和时间保留。状态解释合并进一个原生 details：“状态与连接帮助”，默认关闭，点击或键盘 Enter 展开。具体登录冲突／无法确认登录及“恢复连接”仍按原条件出现，不把必要异常处理藏进帮助。

帮助的展开不触发请求、切换线路、授予权限或改写检测历史。本次只调整展示，不取消浏览器门禁，也不声称解决身份接纳或本机工作空间等待。
