# 最新界面的八种状态

全部为 #652 源码 `334b7967e9ab1a86e4c3ca9314ac08720a65be93` 的真实本地页面截图，使用隔离 Worker/D1/R2、合成用户和测试云盘。不是用户设备故障实录。Service Worker 被测试上下文禁用，不是离线应用壳启动验证。

拼图将原始 PNG 通过 HTML 排版后截图，没有重新绘制产品 UI、修改产品 DOM、替换 controller snapshot 或改写 navigator getter。每格的入口与面板为同一条件下的先后两张截图，不保证同一帧。默认布局、帮助折叠和异常恢复提示都保留。

| 格 | 状态 | 实际触发方式 |
| --- | --- | --- |
| 01 | 正常示例 | 实际登录本地测试用户，两个入口会话均准备好，健康探测成功。只证明该样例的会话／线路条件，不是全部功能就绪保证。 |
| 02 | 检测中 | 测试延迟健康请求，让真实 controller 的 check 保持在途。 |
| 03 | 浏览器离线 | 在健康成功后调用 Playwright context.setOffline(true)，真实浏览器离线；面板保留此前约一秒前的成功样本。 |
| 04 | 连接异常 | 浏览器仍报告联网，测试在传输层阻断两条线路 health 请求。 |
| 05 | 身份需处理 | 页面原先接受测试用户 A 的会话，再通过实际登录接口让直连入口改登测试用户 B；原页面发现会话不一致。未使用真实用户。 |
| 06 | 身份待确认 | 只对测试身份 status 接口注入 503；health 仍成功。当前线路显示待确认，并保留恢复按钮。 |
| 07 | 尚未检测，展开 | 首次请求仍被测试延迟，尚无完成的样本；通过实际 UI 展开采样详情。 |
| 08 | 结果已过期，展开 | 测试将 Date 时钟向前调 46 秒，再推进一秒展示时钟，但不执行新一轮采样；通过实际 UI 展开旧样本详情。不是用户真实时钟异常的证明。 |

实际界面包含至多 20 次采样的点、样本新鲜度及当前线路。本组为比较各状态而固定直连，通常只完成一轮采样；灰色格是尚无样本，不是成功历史。点不代表固定的一秒，也不是持久化连续可用性。不能把这些图作为自动切换证据。当前线路订阅 active，自动切换后的展示由既有 connection-sampling 浏览器回归验证，本次没有增加选路功能。

`capture.json` 记录每格的浏览器信号、检查状态、入口身份和最后样本状态，没有保存 Cookie、会话 ID 或用户凭证。`*-entry.png` 与 `*-panel.png` 是原图；`same-page-652-connection-state-gallery.png` 是排版拼图。

重跑：

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/path/to/local-chromium \
  node scripts/capture-connection-states.mjs
```

脚本只使用本地隔离 fixture；故障请求被测试注入，不连接生产数据库或用户缓存。登录一次后复用该测试会话的浏览器 storageState，避免通过重复登录触碰认证限速；身份冲突格独立登录另一测试用户。没有降低或绕过产品限速。
