# 完整播放器安装复核（#621）

## 收敛后的方案

- 完整播放器是当前版本的必需资源，与 PDF 应用壳共用清单、缓存、完整性校验和回收。只在全部资源校验、存储提交和版本许可成功后切换。下载失败保留已可用版本。
- 跨版本复用只是下载优化：从旧缓存复制与目标 SHA-256、大小及资源类型相符的字节。新版本不依赖旧缓存持续存在，不能复用时正常下载。
- 资源准备进度仅展示已校验保存、已复用和流式接收的资源字节。通知不授予切换许可；最终通知交付等待最多一秒，丢失时可以查询快照，不能无期限阻塞安装。
- MXL/PDF 原文、笔记、身份隔离和发布通道协议保持原格式。离线恢复须核实当前版本与控制器，并继续执行保存、输入、对话框及安全路由门禁。

完整资源约 16 MB（解码后），单版本上限 20 MiB。首次准备通常需要取得完整资源；后续版本按校验结果复用，实际网络传输量另受压缩、缓存状态及内容变化影响。

## CI 两条独立失败链

### 真实 ASSETS 响应没有音色 MIME

真实后端预览的 `sonivox.sf2` 返回 200 和正确文件字节，但没有 `Content-Type`。
新加入的二进制类型检查拒绝该响应，公共读取器抛出 `public_asset_integrity`，整个必需资源安装失败。
等待 `navigator.serviceWorker.ready` 的测试无法完成，最终只表现为超时。
这解释了离线入口、PDF 兼容解码、文件链接等看似不相关的失败：它们都先等待应用壳安装。

原跨版本专项服务器给所有未知扩展补了 `application/octet-stream`，掩盖了这个差异。
现将缺少 MIME 的受支持二进制（音色、字体）作为可校验候选；SHA-256、资源大小及完整版本审计仍决定可用性。
显式 HTML/错误类型仍拒绝，JS/CSS 仍要求正确 MIME。专项服务器也改为不给 `.sf2` 补响应头。
公共读取器的内容/下载失败分别归入已有的完整性/下载失败诊断，不再落入 unknown。

### 跨版本测试污染后续构建

新增专项测试在根目录构建带 `/_releases/<sha>/` 前缀的 A/B 版本，并将 B 留在 `dist`。
后续旧生命周期服务器按不带前缀的本地文件路径服务，且没有发布通道 API，导致 C 无法正常安装、门控请求未到达而超时。

专项测试现在先移动保存原 `dist`，在 finally 中恢复，包括构建或浏览器断言失败时。
备份放在工作目录同一文件系统，兼容 CI 挂载卷与 `/tmp` 不同文件系统的情形。
已注入子构建失败，核对原始构建的 302 个文件逐一 SHA-256 完全一致，且临时目录清理完成。

### 诊断测试的同源页面

完整顺序回归继续执行后，诊断测试的 IndexedDB 阻塞页暴露出旧夹具缺口：`/api/empty` 没有路由，返回空 404，Chromium 会进入浏览器错误页。
现显式返回 200 的同源 HTML，仅用于建立真实存储事务；修订后 Chromium/WebKit 的阻塞超时诊断、草稿保留和不创建缺失数据库的检查均通过。

## Review 重点

保留统一安装生命周期，不新增播放器专用缓存或第二套准备状态机。
旧包只作为校验后复用来源，旧窗口/回退版本的回收保护继续生效；实际 quota 拒绝不清理业务数据。
保留多窗口否决、一秒空闲、发布通道许可及离线恢复的控制器复核。
另补充真实 worker 安装事件测试：客户端进度查询永久不返回时，完整资源仍能在有限通知等待后完成安装。

## 验证

- 生产构建与清单核查通过，完整资源约 16.03 MB，低于 20 MiB 上限。
- lint、typecheck、Node 全量 374 项、客户端全量 1388 项通过；通知等待上限修订后相关 40 项也通过。
- 真实后端 Chromium：PDF 离线读取和替换、离线关闭浏览器后重开、成员失权、文件链接、兼容 PDF 实际解码通过。
- 真实后端 Chromium XML/MXL：上传、离线就绪、关闭浏览器断网启动、谱面、非零音频、刷新再打开和权限撤销通过。
- 真实后端 WebKit 27.2：文件链接、API 故障下新页面离线阅读、成员失权和兼容 PDF 解码通过。
- 完整 PWA 顺序回归由 `npm run test:pwa-update` 串行覆盖：双构建升级、MXL 冷启动、旧壳迁移、quota、版本回收、诊断与发布通道；最终 CI 结果见 PR #621。

本机 Chromium 154；WebKit 运行库仅解包至临时浏览器目录，未改应用依赖。
CI 使用仓库固定的 Playwright 镜像；桌面自动化不宣称完成真实 iOS 的杀进程、音频路由或系统存储淘汰验收。
