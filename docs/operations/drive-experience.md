# 云盘启动、离线与名称管理

默认启动恢复当前用户最后进入的成员云盘，不展示继续阅读卡片。无历史时单云盘直接进入，多云盘显示选择；历史云盘不在最新成员列表时先提示再让用户选择。邀请和深链接优先，乐谱进度仍在主动打开时恢复。

本机目录与在线目录使用同一云盘页面。目录记录的成员关系和能力只用于恢复导航和显示禁用入口，不能授权云端请求；公开体验目录不进入成员云盘切换或启动候选。尚无成员导航记录的旧副本仍可从原乐谱/云盘链接恢复，不由副本推断成员关系。

离线可搜索与排序本机目录；完整校验通过的副本可打开，只有目录的文件显示需联网下载。连接恢复后原地更新。离线仍显示云盘设置齿轮，但在联网确认访问前不可进入设置；本机存储和阅读偏好仍从个人菜单进入。服务端失权与网络故障分别处理，遵守 ADR-0004。

文件库顶部点击云盘名称直接切换已加入云盘，齿轮进入“云盘设置”；窄屏使用设置目录，宽屏使用分类侧栏。个人菜单分组提供当前云盘的显示名、阅读偏好、本机存储，以及账户、帮助、问题反馈和退出登录。加入新云盘、完整云盘列表仍在选择面板中；创建云盘沿用完整列表入口。

名称提交继续使用修订号，冲突时保留输入、展示当前值，须再次保存才覆盖。云盘内显示名只修改当前成员关系，不重写历史笔记署名或归属；拥有权与细粒度授权规则见 CONTEXT 与 ADR-0015。

文件库搜索与当前排序同排，可分别选择依据和方向。触屏从列表顶部下拉更新；个人或访客菜单提供“刷新列表”供键盘/鼠标使用。刷新保留当前视图，不重新加载应用。排序方向兼容旧偏好；导航调整没有新增数据库或 IndexedDB 迁移。


## 发布与验收

部署前应用 `0018_drive_name_revision.sql`。API 的权限与并发测试、页面回归，以及 Chromium 的实际离线重启 / WebKit 的新页 API 故障测试分别提供证据。Playwright WebKit 测试不等同于 iOS 安装 PWA 的离线进程重启。

iOS / Android 安装 PWA 仍须实机验证：从图标启动到最后云盘、断网刷新、切换云盘、恢复联网保持浏览位置，以及管理员交接后的权限变化。PR / CI 通过不代表生产部署或真机验收完成。
