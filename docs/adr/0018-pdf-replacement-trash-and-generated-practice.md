# 替换 PDF 使用回收站，自动生成练习版沿用附件

取代 ADR-0017 中面向用户管理历史 PDF 的规则。替换只更新同一乐谱的 PDF，笔记仍按原页码和位置保留，普通附件不变；旧 PDF 进入回收站，恢复为独立乐谱而不是回滚当前谱，避免让用户承担版本管理，也避免复制成员笔记与附件。

后台保留不可变文件身份、并发校验与已部署接口以保护离线副本和旧客户端；存量保留文件按原到期时间进入回收站，不删除或重新计量。自动生成练习版是每谱最多一份的产品维护 MusicXML 附件，来源不由名称推断，普通上传文件不被自动覆盖；替换时默认保留，取消保留要求删除与恢复文件权限。移除选择持续保留，避免后续生成擅自补回。

## 练习谱展示与附件分离

自动生成练习版继续复用附件身份、修订、授权与回收规则，但从文件库普通附件列表和可见数量中排除；用户上传 MusicXML 仍作为普通附件管理。文件大小旁以小号乐谱图标和“自动练习版”文字安静标明自动生成版可用，不增加徽章或计数。

取代 ADR-0010 中阅读器统一附件入口的决定：工具栏显示时，右下角“练习谱”入口仅列 MusicXML，包含自动生成与用户上传版本；生成版优先、注明“自动生成 · Beta”，上传版保留文件名。单项也先展示列表，由用户明确选择；播放与原 PDF／重排谱面切换沿用现有行为。无 MusicXML 时隐藏入口，音频和其他附件仍从文件库打开。替换 PDF 的保留选择不变。

API 保留 attachmentCount 的全部附件计数语义与目录缓存修订，并新增可选 musicXmlCount、hasGeneratedXml 投影供新界面独立判断。旧客户端继续使用原接口与计数，已有本机目录无需迁移，不修改用户文件、笔记或数据库 schema。
