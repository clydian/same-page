# 用前台成员报告提供云盘使用情况

后台“云盘使用情况”复用 `view_scores` 乐谱运营授权，仅增加云盘聚合读取，不授予成员笔记、邮箱或个人访问记录读取能力。它显示现有真实用量和实际额度（包含人工调整），90% 文件容量提示接近上限；成员数是有效成员关系数，不是活跃人数。入口使用 `/admin?view=usage`，复用既有后台路由，不改变 #671 的安全区布局。

## 访问边界与数据

新版客户端仅在普通云盘目录／乐谱路由的前台进入、恢复、可信 pointerdown/keydown 交互时发出 `POST /api/choirs/:id/visits`。网络可用、云端身份已确认且页面可见才发送；没有定时心跳、离线队列、自动补传或关闭页面 beacon。重新联网只报告当前前台状态，不回填离线时间。失败是可丢失的辅助统计，不影响阅读；下次符合条件的前台交互才再尝试。

报告以低优先级发送到现有、身份已验证的线路地址，不调用会更新健康观测、准备身份或确认切线的公共业务请求流程。线路未准备好时报告失败即丢弃；不为补统计主动切线或重新认证。统计响应不能成为连接面板或目录重启的线路证据。

专用请求头标明报告用途并携带现有 user-ID 身份 fence；服务端重新校验会话、有效成员关系、云盘未删除且非公开体验，以服务端毫秒时间记账。SQL 在同一次写入中再次约束会话和成员，且排除任意 product／diagnostic／release operator（即使该身份同时是成员），避免运营检查污染使用。该用途头不是安全凭证，也不能证明真实人类在阅读；恶意的有效成员可以伪造前台报告，数字不适合作为安全、计费或清退凭据。后台查询、目录轮询、预取和笔记同步均不会记账。

客户端每个挂载报告周期最多每五分钟尝试一次；服务端原子 UPSERT 每个成员关系最多每五分钟更新一次，多标签页并发不会增加行或突破写入节流，时钟由服务端决定，不接受客户端时间。恢复前台/切换路由不会补齐两次样本间的行为。边界最多约五分钟采样误差，7/30 天人数是已记录的下界，不是准确活跃全量；不做阅读时长推算。无交互的长时间阅读不持续刷新。

`drive_member_visits` 每个成员关系仅一行最近时间。索引支持按盘、时间筛选；每小时清除超过三十天的成员级记录，不删除云盘、内容或成员身份。成员关系物理删除及云盘物理删除通过外键级联。移除成员、用户删除后汇总立即排除；恢复后若保留的样本仍在窗口内可重新计入。运营身份按**报告发生时**排除：成员后来成为产品管理员，不抹去此前合法报告，后续管理员报告不刷新样本；汇总不按当前管理员名单追溯删除历史。`choirs.last_member_visit_at` 由触发器单调更新，是不含成员身份的最后已知访问，成员退出和样本过期不抹掉该事实。

新迁移记录全局服务端采集开始时间。没有任何历史时间回填；没有记录的最后访问显示“未知”。创建早于采集开始、窗口跨越采集开始的盘，其人数显示“未知（已记录 N）”；创建在采集开始之后的盘不需要虚构创建前访问。即使窗口完整，也只显示新版客户端收到的报告，不能把零当作无人使用。公开体验明确“不统计”。使用完整滚动 24 小时窗口，页面统一展示北京时间并给更新时间；不是自然日 DAU，也不包含已经失效的成员关系。

## 迁移、回退与验证

先应用增量迁移 `0040_drive_visits.sql`，再发布 Worker，最后客户端。迁移只加 nullable 聚合字段、空表、索引和触发器，不更改原数据、额度、权限或用户持久格式。旧 Worker／客户端可以继续运行，不发送报告即没有数据。新客户端遇到旧 Worker 的 404 丢弃统计；新后台应在 Worker 升级后开放。采集开始时间是数据库具备接收能力的时间，不能证明客户端从该刻全部更新。

回退代码时保留新增字段与表，不执行反向删表；旧代码不依赖它们。**支持的 Worker 回退产物必须保留 `cleanupDriveVisits` 和现有每小时 cron 的调用**，即使回退客户端或不再接收访问报告。不能直接部署完全没有该清理任务的旧二进制并继续保留成员级记录；应从目标旧代码构建仅保留此清理函数／入口的维护版本，验证逾期成员记录被清除、云盘及聚合时间保留后再切流。生产迁移与部署均需另外安排，本次仅提供 draft PR。

旧代码维护版本可在原 `scheduled` 入口保留以下独立语句；它只依赖原有 DB binding 和新增表，不需要新的前台代码或上报接口。实际构建、验证、发布属于另行授权的回退操作：

```ts
context.waitUntil(env.DB.prepare("DELETE FROM drive_member_visits WHERE last_seen_at < ?")
  .bind(Date.now() - 30 * 24 * 60 * 60_000).run());
```

用真实本地 D1 验证身份、有效成员、运营者与公开体验排除、原子节流、窗口边界、删除与数据保留；客户端检查可见性、离线、身份切换与无定时报告；浏览器覆盖真实成员进入→后台聚合，截图只使用合成数据。该决策补充 ADR-0019，不改变个人层隐私；不实现通知、闲置工作台、自动或人工清理操作。现有闲置 runbook 的可靠证据要求仍适用。
