# 产品运营后台使用独立授权与候选检查发布

## 决策

实现 #433，补充 ADR-0006。产品运营权限独立于云盘成员关系与 ADR-0015 的授权体系；按稳定 user ID 授予查看、检查、发布能力，云盘另需显式纳入试点。迁移不授予任何运营权限、不启用任何云盘。普通云盘接口不增加运营者绕过逻辑。

候选练习版绑定原 PDF 的不可变版本与校验值，单独保存文件、检查修订及来源信息。检查页复用用户播放器的 MusicXmlPractice、PracticePlayerShell、Chorus/alphaTab 及现有 PDF.js 预览；权限、文件加载、会话释放由后台自己负责，不使用成员笔记工作空间、离线目录或用户练习偏好。

正式发布继续使用 ADR-0018 的每谱生成版单槽与旧客户端附件协议。独立复制候选文件到正式附件命名空间，避免附件更新触发器删除历史候选。最终 SQL 操作同时验证会话及运营授权、试点、父资源存活、来源 PDF、审核修订、用户移除选择、正式附件修订和配额，写入发布/操作记录并更新当前附件。R2 文件在提交前准备，以持久 staging 记录回收未提交文件。重试使用固定 publication ID；重新发布历史结果形成新的附件修订。

格式验证与播放器渲染成功、人工检查是三件事。服务端验证 MusicXML 格式及校验值；受信任运营者的客户端只有渲染/播放器准备成功才可提交技术检查通过，审核结论记录这一声明。它不代表自动判断音准正确。

## 容量与生命周期

候选与历史结果保留 30 天，pending 上传一小时后回收，产品独立候选与发布暂存容量默认 1 GiB，可通过维护操作调整 `product_admin_limits`。失败结果占用预留容量直到到期；其失败对象会进入删除队列。正式生成版继续计入云盘附件额度。操作和发布记录保留 90 天，不写谱面或笔记正文。

候选随来源 PDF 版本的实际清理而删除，可能早于自身 30 天期限；这不会影响已发布的独立附件文件。彻底删除父云盘/乐谱后立即拒绝访问，下次清理释放候选。回收站内容也不提供后台预览。停用试点停止访问，不改变普通用户已有正式版。

## 取舍

采用数据库运营授权而非将运营者加入所有云盘，防止成员管理、笔记读取和活跃统计扩权。初期复用同站登录和部署，接口单独鉴权；未接识谱引擎，也不引入任务调度基础设施。30 天文件历史不是永久版本库，后台仅在保留期内支持比较。
