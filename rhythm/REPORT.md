# 视唱速度、节拍和跨八度验收

产品提交 `9ae353094a71a0b6074c4a219298b8ceaf7f8ea6`。浏览器测试使用完整的生产构建、合成 SATB MusicXML 与 48 kHz 合成演唱。测试经过实际 AudioWorklet、Pitchy、AlphaTab 点击音频、Web Audio 和本地钢琴混音。Sites 答题接口用浏览器内的夹具模拟。浏览器确认拍声加载 XML 播放器的同一版音色，路径也在生产构建的离线清单中。

| 场景 | 预期与实际 |
| --- | --- |
| 390px 中文浅色，4/4，0.75× | 四个音整体低一八度，100 分。256,000 个样本对应 5.333 秒，预备加两小节共 12 拍，相邻拍间隔约 0.667 秒 |
| 1200px 英文深色，4/4，1× | 整体低一八度，第一个 E3 再高 35 音分，75 分。反馈显示 E4 目标、E3 实唱及 +35 音分 |
| 390px 中文浅色，6/8 | 首拍、第四拍和其余拍的 PCM 峰值约为 0.137、0.107 和 0.089。预备加四小节共 30 拍，每拍约 0.333 秒 |

结果沿用原谱。以 0.75× 点击第 2 小节时回听跳至约 2.667 秒，点击第一条逐音反馈回到开头，挥发性录音混合跟随实际演唱八度的钢琴答案。音高图将轨迹对齐到谱面音区，当前音符和逐音列表仍展示实际唱的音名与八度。

截图为这三组操作的真实页面。结构化指标见 `metrics.json`。验收脚本需要在装有 Playwright Chromium 的合谱工作区中运行，并将 `SIGHT_QA_URL` 指向部署前的本机 Sites 静态构建。实验没有测量 iPad 的音频路由及真人和外放串音。
