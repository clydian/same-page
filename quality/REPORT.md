## Ella 对照

直接查看了官方演示视频和音符反馈图。视频约 11–13 秒保留乐谱和轨迹，同时给出 Notes、Intonation、Interval 和 Retry／Next／Review。练中能看见乐谱、轨迹和 Stop。单音图将细节和谱面音符对应。App Store 截图复核演唱及单音反馈，2025.5 的版本记录说明 v2 改进记谱可读性并响应输入。 [官方视频](https://www.ensemble-education.com/apps/ella/top.mp4) · [官方反馈图](https://www.ensemble-education.com/apps/ella/feedback.webp) · [App Store](https://apps.apple.com/us/app/ella-sight-singing-reading/id1301456113)

官方 FAQ 将 Notes 定义为唱对的音数，Intonation 衡量绝对音准，Interval 衡量相邻音程，并把题目分析和游戏计分分开。FAQ 同时说明整段和单音录音回听。合谱自己的设计判断是让用户一直能看到谱面，在结果里点目标音后从该音的位置开始播本次录音。公开资料给出了交互和评分指标的含义。 [Ella FAQ](https://www.ensemble-education.com/faq-ella)

## 方法

用同一份 MusicXML 和逐音标注在 44.1／48 kHz 分别跑 15 次。合成声源用三种泛音谱、起音弯音和气声、轻微颤音、包络和固定种子噪声，保留每个音的预期分类。普通音符为 250–500 ms，快速音符为 62.5–125 ms。背景噪声样例的真值均为漏唱。

Chromium 使用隔离的版本化构建和合成云盘 fixture。浏览器拿到假麦克风权限和轨道，脚本将标注 PCM 量化为 16 位后注入 Web Audio 输入节点，后续由真实 AudioWorklet 切分，经 Pitchy、判分、DOM 和 WAV 回听路径。脚本核对录音的 WAV 采样率。这里的绝对起唱时间由输入样本控制；真实收音延迟和音频路由未知。对照不接触生产、私人乐谱或真实录音。

截图来自同一基线和候选，在 Chromium 390×844／1200×1030 视口复查。组合为中文手机浅色、英文手机深色、英文桌面浅色、中文桌面深色。每个组合有待练、预备、演唱、结果，候选额外核对点击第三个目标音后的回听及重试。中文桌面深色的回听图捕捉了结果行与谱上当前位置。所有图均为应用真实画面，数据为合成样例。手机尺寸代表视口测试，仍需在 iPad Safari 与主屏幕入口真人试唱。

## 重跑

将同目录的 `browser.mjs` 和 `sources.mjs` 一起下载到临时目录。从相应的合谱 Git checkout 安装依赖和 Playwright Chromium，运行以下命令。基线不需要 `SIGHT_CHECK_REVIEW`，候选会额外检查谱上当前音、逐音回听和重试。

```sh
npm ci
npx playwright install chromium
node /path/to/evidence/browser.mjs /tmp/sight-before
SIGHT_CHECK_REVIEW=1 node /path/to/evidence/browser.mjs /tmp/sight-after
```

仓库内的确定性回归保留旧步长的无帧／有帧静音对照，并验证新步长在原理想帧控例中的覆盖。上表独立来自真实浏览器处理合成音频的结果。
