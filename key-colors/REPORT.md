# 调内网格与谱面结果着色

产品提交 `73a0d748174d5fb0b4ff102475328ce67fad6409`。使用合成四声部 MusicXML、G 大调转 F 大调和 48 kHz 标注音频。Chromium 在手机浅色中文和桌面深色英文中通过实际 AudioWorklet 与 Pitchy 检测。题目通过隔离试玩的上传流程建立，数据只在标签页。

- 播放头在 G 大调时，F♯ 是调内音。在 F 大调时，F 和 B♭ 是调内音。Canvas 的网格加深只覆盖调号适用的时间段。单测另覆盖小节中的调号变化、反复和速度缩放。
- 测试唱准、偏高 35 音分、错一半音和漏唱。符头分别显示绿、橙、红、红。只给匹配的和弦音着色，其他声部保留淡色。符头按钮提供对应文字反馈，逐音表和结果摘要可读。重试时清除颜色。
- 手机截图和桌面截图均来自真实构建。iPad 真机尚未验证。

在产品工作区运行 `node verify.mjs`。设 `SIGHT_QA_URL` 为隔离静态试玩地址，`SIGHT_QA_BUILD` 为完整产品提交，`SIGHT_QA_THEME=dark` 可复查桌面深色。
