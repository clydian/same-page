# 产品后台界面原型（可丢弃）

对应 Issue #433。仅模拟数据，状态只在内存中，刷新或重置后清空，不接任何产品 API，不部署。

在此工作区安装依赖后运行：

```sh
npm run prototype:admin
```

打开 http://127.0.0.1:4399/prototype/admin?variant=A 。底部切换 A（乐谱总表）、B（按云盘浏览）、C（待检查看板），也可用左右方向键；输入框内不拦截方向键。切换器仅在开发模式显示。

建议体验：

1. 跨云盘筛选与搜索，选择“月亮代表我的心”的“导入 XML”。
2. 使用内置示例，或导入本机 .musicxml/.xml。文件只在浏览器内存中处理，不上传服务器；原型不支持压缩 .mxl。
3. 左边的 PDF 是手绘示意，不是实际上传文件；右边用 Chorus/alphaTab 真实渲染和播放 XML。预置历史/正式结果均为同一示例，比较仅展示交互切换，不代表真实质量差异。
4. 核对三项，标记检查通过，再模拟发布。返回列表看正式结果和操作记录。
5. 在“体验异常情况”中模拟成员更换 PDF，观察发布被禁用。用户已移除的示例也不可发布。

问题：哪种信息组织更适合日常运营？导入、检查、发布是否容易理解？目前尚无用户选择的结论，不能视为已批准的产品设计。

边界：不实现真实登录、权限、存储、审核事务、配额或自动识谱。不将此实现直接合入生产代码。未部署、未做音准或真实设备声音验收。
