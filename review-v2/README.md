## 实际发现并修复的混音问题

新观测确实复现了换色后关注仍显示80%/15%、合成器却收到1/1的错误。原生代理在midiLoaded前按旧flags发ready，随后在预设真正就绪后再发ready并重设谱面音量。只等midiLoaded或任意ready都过早。现在等midiLoaded之后的ready，才恢复tick、循环与会话混音；无新增计时等待、延超时或放宽断言。

verify.mjs在现有会话设置独立音量65%/45%，开启关注并调为80%/15%，换哦声后检查真实alphaSynth.setChannelVolume仍是80%/15%；关闭关注恢复65%/45%。具体观察见focus.json。现有musicxml-playback Chromium场景也加入简短回归，并实际通过。
