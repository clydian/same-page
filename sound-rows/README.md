# 声部混音：直接音色行

产品提交：c0ba71b，基于main 4872cc9。截图与证据独立保存，不属于产品diff。

## 最终界面

声部音色默认折叠。展开后按音量区相同顺序列出Soprano、Alto、Tenor、Bass，每行名称和一个直接选择音色的控件。每行可恢复默认播放音色，不需要先选择声部。沿用混音区的间距、分隔和原生选择控件，没有额外内层卡片，仅保留一条会话提示。

桌面1024×1000、窄屏390×844。四张图已实际打开查看：collapsed-desktop/mobile显示默认折叠；expanded-desktop/mobile显示四行，Soprano实际改为钢琴、Alto实际改为哦声。窄屏四个选择框完整可达；内容超出时沿用既有面板内部滚动，标题与关闭入口保持可见。没有新增浮层、持久化或音色浏览器。

## 真实验证

生产构建、Chromium156、本地Worker/D1/R2，正常上传合成SATB四声部谱，不使用私有谱。verify.mjs执行功能验证，capture.mjs生成截图。

- 四个声部顺序正确，折叠时无音色选择框；展开后同时出现四行。
- 改Soprano到钢琴时，其他三个通道的完整MIDI事件与初始值严格相等；再改Alto到哦声，Soprano选择保持，Tenor/Bass保持默认。
- 关注开时换色，实际发送给AlphaSynth的通道音量保持80%/15%/15%/15%；关闭关注恢复65%/45%/75%/75%。
- 换色保留当前位置、循环第4–8小节、独奏。播放中再更换Bass，播放继续；恢复所有声部默认后全部实际MIDI严格等于初始加载。
- actual-midi.json是实际发往合成器Worker的MIDI。programs.json显示每次加载的四通道program：52/52/52/52 → 0/52/52/52 → 0/53/52/52 → 0/53/52/0 → 52/53/52/0 → 52/52/52/0 → 52/52/52/52。
- verification.json包含通道音量、窄屏选择框尺寸及0页面错误的观察。
- 相关播放器31项、客户端设置/循环7项通过；现有MusicXML attachment practice and PDF handoff Chromium场景1项通过，使用直接声部行选择。
- lint、生产build（含TypeScript检查/预缓存）、10语言检查2226消息、git diff --check通过。

## 验证边界

选择仅用于本次打开会话、当前乐章。更换会短暂重载当前MIDI，保留播放位置及混音。未修改源XML、谱面模型、离线原件/缓存、其他用户或其他谱面。
