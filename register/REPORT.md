# 视唱音区与换气处断线

产品提交 `6b0270a9f664a36b522dca90841010b5b843a454`。用八小节四声部合成 MusicXML 和 48 kHz 标注音频，Chromium 通过实际 AudioWorklet 与 Pitchy 检测。在第 3 到 4 小节和第 7 到 8 小节插入短促有音高的瞬态及低电平噪声。使用中文手机视口和英文桌面深色主题。当前输入用合成信号模拟过渡，尚未复测实际吸气、真人声音和 iPad。

- 原先的独立图会把尾端杂音与连续演唱连起来。在桌面截图中，16–18 秒附近可见贯穿图面的细长跳线。
- 新版只显示获得连续支持的音高。未确认的瞬态保留为空，音高大跳处分段。持续唱到不同八度时保留新轨迹。两个示例边界的轨迹均断开，结果仍为 100 分。
- 独立图每半音 16 CSS px。默认 192 CSS px 高，显示约一八度。E3 到 F5 时，同一音高窗的滚动位置由 537 改为 137。回听到 F5 时同样到 137。实线对应原谱，虚线对应可唱的其他八度。
- 键盘 PageDown 与移动触摸滑动可浏览音区。手动移动后退出跟随，点击「跟随音高」回到当前演唱音区。

`verify.mjs` 在产品工作区运行。设 `SIGHT_QA_URL` 为待测静态构建，`SIGHT_QA_BUILD` 为产品提交，`SIGHT_QA_MODE=fixed` 核对新版。设 `SIGHT_QA_THEME=dark` 可复查英文桌面深色。模拟器麦克风权限由 Chromium 提供，输入只使用脚本生成的样本。
